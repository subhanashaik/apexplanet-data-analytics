# apexplanet-data-analytics
ApexPlanet Data Analytics Internship Project – Task 1: Foundational Setup and Exploratory Data Analysis using Python, Pandas, NumPy, Matplotlib, Seaborn, and Jupyter Notebook. This repository contains data cleaning, statistical analysis, data visualization, outlier detection, correlation analysis, and key insights from the Superstore dataset.
The main objective of this project is to perform Exploratory Data Analysis(EDA) on the sample SuperStore dataset using python.
